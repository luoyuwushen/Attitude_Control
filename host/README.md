# J280 姿态控制测量工作站

## 当前版本 host-v0.7.0

配套 project-v0.3.0。主界面分别显示 ADC 原始均值和控制均值，水平盲区显示“暂不可测”。在该区间不能标定或启动；扶回有效直立区、等待有效和就绪后再按 H。测量恢复不会自动启动，盲区本身无需 R。仍有硬故障时按具体原因恢复。

目标从松手不倒推进到尽量静止：连续 60 秒，末 20 秒摆臂峰峰 ≤5°，进一步 ≤2°，摆杆相对零点 RMS ≤2°；同一标定和参数下连续通过 3 次。记录松手时刻，正常停止并导出控制记录。该目标尚待新版上板验收，详见 [目标与基线](../docs/H稳定目标与日志基线.md)。

配套软件支持 219 字节 v2 的 TLV34 和独立盲区／尖峰提示；旧日志保持原义。以下旧版本章节为功能历史，当前协议以 [PROTOCOL](PROTOCOL.md) 为准。

上位机当前版本 **host-v0.7.0（2026-10-06）**，支持 project-v0.3.0 的 219 字节遥测与停止后的连续控制记录导出，并兼容 project-v0.2.9 的 215 字节帧及此前 v1/v2。实验记录在后台创建、写入和保存，界面显示保存进度与结果。连接后自动记录平衡调参所需的actual、target、out、速度、积分和故障，保留原始帧供复核。旧固件未提供的H参考和积分不会补造，控制算法身份未知时目标留空。

使用 project-v0.3.0 或 project-v0.2.9 完成一次 H 并停止后，在左侧控制栏向下滚动，可点停止按钮下方的 **导出连续控制记录**，读取停止前最后约4秒的1kHz控制更新。等待界面显示已保存，再断开或进行下一次H。结果单独保存在 `captures/control_traces/`，包含JSON原始证据和CSV数据；正常运行日志仍在 `captures/fpga_logs/`。导出中当前状态继续刷新，历史数据不进入实时曲线。缺包、断连或保存失败会明确提示，不能作为完整记录使用。

H接管顺序：**扶稳近直立 → 点击H → 确认当前状态为直立平衡 → 再松手**。发送完成不是设备接纳；等待、超时或仍待机时不要按已接管处理。提示只说明观测到的设备状态，不保证机械已稳定。

## 启动

Windows 本机发布包为 `Project/Release/host-v0.6.9/J280_Monitor.exe`；同目录的 `HOST_README.md` 和 `HOST_PROTOCOL.md` 提供说明。EXE 为本地产物，不包含在源码仓库中，克隆后可按下文自行打包。源码运行时，在 `Project` 执行：

```powershell
python -m pip install -r host/requirements.txt
python tools/host_monitor.py --demo
```

依赖包括 PySide6-Essentials、pyqtgraph 和 pyserial。演示模式明确标示“非实测”，可体验曲线、截图和记录；不会发送设备命令。打开已有 CSV 可回放，支持暂停及 0.5×、1×、2×、4×速度。“冻结曲线”只暂停绘图，采集与记录继续。

## 平衡调参日志

自 host-v0.6.5 起，项目串口连接后自动生成 `captures/fpga_logs/<会话>/tuning.csv`，无需点击“开始记录”。该文件可用表格软件或分析脚本打开，正常断开或退出后查看完整尾部。完整遥测与原始帧仍在同目录 `telemetry.jsonl`；操作及手动标记在 `control.jsonl`，单位和已知参数定义在 `metadata.json`。host-v0.6.6 保留这些字段与元数据定义。需要上位机CSV回放时，使用实验记录生成的完整 `samples.csv`。

| 主要列 | 含义 |
| --- | --- |
| actual / target | 摆杆实际/目标角度，单位°；目标仅在已识别的活动H控制中提供 |
| out | 请求PWM千分比，1000为100%；不是实测电机输出 |
| actual_valid / active | 测量可信条件是否成立 / 已识别的H是否活动；空值表示无法确认 |
| error_deg / arm_error_deg | 目标减实际；仅在活动H且测量有效时填写 |
| arm_actual_deg / arm_target_deg | 摆臂实际位置/H接管参考位置，单位° |
| omega_rad_s / arm_speed_rad_s | 摆杆/摆臂角速度 |
| integral_permille / h_control_flags | 当前命令的积分观测及更新、冻结、限幅状态 |
| motor_command_permille / requested_saturated | 门控后软件命令 / 平衡请求是否达±1000‰ |
| parameter_profile / algorithm | 对应固件的参数定义 / 当前已识别算法 |
| state / fault / first_fault | 当前状态、故障和首次故障 |

project-v0.2.6～v0.2.8的 H 使用四状态反馈与摆臂居中积分，日志记为`H_LQI`。v0.2.6参数组为`H_LQI_Qi1`，v0.2.7为`H_LQI_S110`，v0.2.8为`H_LQI_S120`；后两版分别将摆臂速度项系数幅值设为v0.2.6的约110%、120%。v0.2.7实测已减小往返但仍周期晃动，v0.2.8是下一对照候选。积分作用于摆臂位置误差，不能把所列增益直接当作传统摆杆单环PID的Kp/Ki/Kd。`metadata.json`保留各版各自的四项增益、积分系数、幅值/速率限制和渐入规则；这些是版本定义，不表示支持串口在线写参数。日志约50Hz，不能重建全部1kHz控制过程。

## 串口设置与连接

先关闭占用同一串口的官方工具，选择核心板 CH340 的实际 COM 号。在“设置”中选择工作模式和串口参数，保存后点击“连接串口”；连接期间参数锁定，修改前须断开。

上位机将原始缓存与文本显示分别限制大小，避免长时间接收后界面积压。“保存接收字节”仍导出末 256 KiB 原始数据；终端窗口只显示末段，完整采集应使用实验记录或串口日志。升级时先用 SW3 停止并完全松开，保存当前记录，关闭旧程序后启动新 EXE；保留同一套件的 `captures/host_preferences.json` 可沿用设置。只换上位机且 FPGA 未复位时，无需重复 D/U 标定。实板长时稳定性仍需复验。

| 设置 | 支持值 | 用法 |
| --- | --- | --- |
| 波特率 | 1～4000000 的整数 | 可直接输入；点击“加入常用波特率”添加多个自定义值，保存后下次启动保留 |
| 数据位 | 5、6、7、8 | 与设备端保持一致 |
| 校验位 | N 无校验、E 偶校验、O 奇校验、M 标记校验、S 空校验 | 是否可用取决于串口驱动 |
| 停止位 | 1、1.5、2 | 是否可用取决于串口驱动 |
| 工作模式 | J280 遥测与控制、通用串口收发 | 两种模式须断开后切换 |

**当前及旧项目 FPGA 均固定为 115200、8N1。** 点击“恢复 J280 默认”可恢复匹配配置；修改上位机参数不会修改 FPGA。J280 模式选用其他参数时，所有项目控制命令均禁用，包括串口停止命令；停止机构使用板上 SW3。

串口设置、常用波特率和日志开关保存在采集目录的 `host_preferences.json`；源码默认位于 `Project/Release/captures`，EXE 位于同目录 `captures`，`--output` 可指定其他目录。删除该偏好文件后，下次启动恢复默认设置并关闭可选串口/控制日志；项目连接的自动 FPGA 运行日志仍保留；每次启动显示主界面。

“通用串口收发”提供 HEX 和文本收发，可查看官方例程或其他设备的原始数据。文本编码支持 UTF-8、GBK、ASCII，换行默认“不附加换行”，也可显式选择 LF、CR 或 CRLF；HEX 发送仅按输入字节发送，换行须写入 `0A`、`0D` 等字节。通用模式不自动发 `S`，不解析为本项目遥测；原始日志不能直接用于项目曲线和辨识。单次发送最多 4096 字节；数据位小于 8 时，超过该位宽的字节会被拒绝，避免静默截断。收发字节数可用于核对通信量；完整写入串口不等于设备执行成功。

接收默认显示 HEX，可切换文本编码。接收缓存只保留最后 256 KiB；“保存接收字节”将当前缓存保存为 `.bin`，不是无限连续记录。J280 模式也可查看原始接收，任意字节发送只在通用模式开放。

## J280 标定与运行

使用默认串口配置，收到最新有效遥测后再操作。主界面“开发板控制”提供 D/U 标定、方向核验、G 起摆与平衡、H 直立接管、F/B 限时点动、R 清除故障和 S 停止（满足健康恢复条件时R也可清传感器锁存；旧板按其旧语义）。D、U、G、S 分别对应板上 SW1、SW4、SW2、SW3；**SW5 系统复位继续使用板上按键，R 不等于系统复位。** 开发者模式用于测量与分析。

1. 按一下 SW3 并完全松开，或发送 `S`，待机构停稳。摆杆自然下垂时记录 `D`。
2. 保持停机，扶至直立后记录 `U`；检查标定完成、直立角接近零。两位置须在同一连续电位器区间。
3. 先停机核验角度/编码器及运动范围。本人在场、运动空间清空且准备按 SW3 后，勾选“点动前已确认运动空间，并准备按 SW3”，可用 F/B 完成首次电机方向核验。F/B 仍要求数据新鲜、已标定、待机、无故障及 SW3 释放；每次 10% 指令、最多 150 ms，不连续续期。核验方向、盲区和范围全部完成后，才勾选“已核验方向、盲区与运动范围”以允许 G。每次新连接清空两项确认。
4. 新固件先用 H 进行直立接管对照：保持近直立、低速且全部核验条件满足时发送；未满足条件不会施加起摆脉冲。实际接管和平衡通过后，再从自然下垂发送 `G` 自动起摆。点击停止或按 `Esc` 发送 `S`；异常时使用板上 SW3。

仅 J280 模式且配置为 115200、8N1 时，默认断开或退出尝试发送 `S`，串口故障时不能保证收到。先确认机构停止再关闭；旧命令行 `telemetry_monitor.py` 退出不会自动发 `S`。命令没有 ACK，“已写入”不代表执行成功，应检查遥测反馈。重新上电、复位或下载后需要重做 D/U。

## 启动条件与 FPGA 诊断

G 按钮下方的“起摆条件”即时说明当前为何不能发送，包括连接/串口格式、数据超时、SW3 未释放、非待机、未标定、故障或方向核验尚未完成；勾选项改变时立即更新，按钮提示保留具体原因。F/B 允许独立的点动前确认，解决先核验电机方向才能点动的循环；G 仍要求完整方向核验。两类操作均检查数据新鲜、标定、待机、故障和 SW3；不能以虚假确认、通用串口或板上 SW2 绕过现场条件。

每次重连清空上一连接的接收时间和两项操作确认。上位机收到连接成功通知后，最多等待首帧 1 秒并显示“等待 FPGA 首帧遥测”，这段等待不记成数据超时；超过 1 秒仍无有效帧才报告超时。等待期间运动按钮始终禁用，收到帧后仍按接收线程时间判断新鲜度。

支持诊断的 FPGA 在主界面显示最近一次 SW2/G 被接受或被拒收的原因，以及当前 SW3 同步停止、ADC 过量程、接口锁存与估计器锁存异常。最近结果为历史记录，当前条件变化后不会自动改写；S/R 保留它，停机 D/U 可清除。旧 project-v0.1.1 未提供此诊断时显示“未提供”，不当成正常。故障时角度可能保留最后可信值。

project-v0.1.3 将电机驱动与编码器统一到原配 XH1（TB6612 B 桥）；XH2 的 A 桥停止。若状态已起摆、有非零指令而电机不动，先用 SW3 停止，核对实际位流、XH1 接线和底板 12 V 供电。串口可用不能证明电机已经供电，控制指令也不是实测输出电压。

## 自动保留 FPGA 运行日志

真实 J280 项目连接且配置为 115200/8N1 时自动记录，无需打开日志开关或点击“开始实验记录”。每次连接在 `captures/fpga_logs/<时间戳与会话编号>/` 单独保存，界面显示当前目录；演示、回放和通用模式不生成 FPGA 实测运行日志。

| 文件 | 内容 |
| --- | --- |
| `metadata.json` | 上位机版本、兼容项目基线、COM 与完整串口配置；不是自动识别的板上固件版本 |
| `telemetry.jsonl` | 每帧有效遥测、原始数值、启动诊断及主机接收时间，供后续复核 |
| `control.jsonl` | 连接/断开、命令排队/拒绝/写入、操作确认、G/H/F/B/J/K/L/M 可用条件及定PWM档位、状态与故障变化、通信异常及当时遥测上下文 |

文件按实际出现的数据生成；尚无有效帧时不会伪造遥测文件。自动日志不保存完整坏帧字节流，需要原始 RX/TX 时另开下一节的可选日志。磁盘错误或队列满会显示“日志不完整”，排除保存路径或空间问题后重新连接；异常退出可能丢失尾部。

`operator_checks` 记录方向核验及点动前确认的初始值与变化；`control_availability` 记录 G/H/F/B/J/K/L/M 是否可用、禁用原因及 `motor_test_permille` 档位，仅在条件变化时追加。它们反映电脑端的操作声明与许可，不证明设备已执行、方向已实测或机械条件符合要求；协议字段见 `PROTOCOL.md`。

串口交付队列达到容量上限时会报错并结束连接，不能把报错前后数据拼成完整实验。断开和关闭异步处理，阻塞写入不会占用界面命令派发锁；已开始的写入无法撤回，通信故障仍使用 SW3。帧龄依接收时刻计算，数据过期不允许继续运动操作。

## 实验与记录

“开始实验记录”可填写名称、板号、固件 Git 版本、方向参数、实测单圈计数、安装与测试条件；未知项留空。默认保存到 `Project/Release/captures/session_*`，EXE 移动后保存到其同目录的 `captures`；可用 `--output` 指定目录。

host-v0.6.6 会先显示“正在创建实验记录”，创建完成后显示记录目录。点击“结束记录并生成摘要”后，界面显示“正在保存实验记录”和“正在保存尾部记录”；此时还没有保存成功。待已接收的记录写完、文件关闭及摘要生成后，才显示“记录已保存”。保存完成前不能开始新实验，采集与停止 S 仍可使用；关闭窗口时会等待实验记录收尾，完成后自动退出，请勿强制结束程序。

保存路径不可写、磁盘空间不足或待写队列满时，会明确显示“记录不完整”及错误，不会将部分文件报告为保存成功。采集和停止操作仍可继续；待本次收尾结束，排除磁盘或路径问题后再新建记录，不把失败前后的文件当作完整连续实验。

实验记录的后台磁盘处理不要求界面等待磁盘。自动 FPGA 运行日志和可选串口日志仍按各自的保存、关闭规则处理；本版实验记录改进不代表所有日志的退出等待都已消除。

每次记录包含 `metadata.json`、`samples.csv`、有效原始帧 `raw_frames.bin`、事件 `events.jsonl` 和结束时生成的 `summary.json`。主界面可添加人工标记、保存曲线 PNG；在开发者模式的“实验指标”页查看分析结果，轻推撤手后点击该页“标记扰动结束”，按所设角度带和连续保持时间判断恢复。默认 ±2°、0.5 秒是项目参考标准，手推不是已测力矩。

CSV 同时保存四个状态量的原始 Q10 与转换值。指标包括首次捕获时间、捕获次数、平衡 RMS/偏置/峰值、最长连续平衡及 ±2° 保持时间、摆臂范围，以及起摆/平衡限幅比例；平衡与恢复只使用明确已标定、无控制器故障的样本。缺帧和长接收间隔会打断连续保持判断。回放要求有效样本在同一时间列上有有限时间值，时间缺失会提示错误；再次记录、回放仍保留最初的演示或实测来源。

## 开发者模式：补齐待测数据

点击“设置 → 进入开发者模式”，当前窗口切换到测量页面，提供“实测与辨识”“实验指标”“扩展遥测”三页。点击顶部“返回主界面”恢复控制页面；切换不重连串口、不清空数据、不停止实验记录或日志。两个页面顶部始终提供停止 S，Esc 同样可用。进入开发者模式不会保存设置中尚未提交的修改，需先“保存设置”再进入。

在“实测与辨识”选择测量项目和“当前数据窗口”（1～120 秒），采集后点击“计算当前窗口”。演示与回放保留来源标识，演示结果不会标成实物测量，回放不代表本次现场实测。串口数据过期时不能继续计算；丢帧、重复、复位、时间倒退或超过 100 ms 的接收间隔会拒绝连续辨识。修改计算参数后需重新计算再保存。

| 测量项目 | 操作 | 输出及边界 |
| --- | --- | --- |
| ADC 静态噪声 / 标定辅助 | 停机并保持静止；下垂、直立各保持至少 1 秒后保存末 1 秒静态段，再计算 | ADC 均值、标准差、范围；已标定且无故障时附角度噪声。保存静态段只记录数据，不发送 D/U；整数 ADC 遥测不是内部 Q4 标定寄存器 |
| 编码器单圈 / 已知角度计数 | 填入本次固件 `COUNTS_PER_REV`、`ENCODER_SIGN`；停机且已标定，记录稳定起点，手动转过独立测得的角度后记录稳定终点，填入带方向的实际转角，默认 0 不可用于计算 | 计数差与 CPR 估计。可用安全的小角度，不必强行转满一圈；不能把软件显示的 360° 当机械参考 |
| ADC 有效区 / 疑似盲区扫描 | 停机，缓慢手动扫描，选择覆盖扫描的窗口；可在未标定的待机状态采集；默认相邻跳变阈值为 32 码 | ADC 范围、近电压轨及跳变/故障采样点。须结合机械参考与录像定位，不能单凭跳变得到盲区角度或电气行程 |
| 下垂自由衰减 | 完成标定，固定摆臂；摆杆偏离下垂约 5～10° 后轻轻释放，保留至少 4 个同侧峰；可填写已测静态角度噪声 | 衰减周期、振幅衰减率、归一化 `b/J` 和 `mgd/J`。整段须在下垂 ±15° 内，摆臂变化默认不超过 2°；拟合不满足条件时不输出。不能由此得到绝对惯量、绝对阻尼或质量 |
| 点动 / 滑行响应 | 在主界面满足核验条件后进行一次 F/B 限时点动，再进入开发者模式分析；窗口包含点动前后各至少 3 帧待机数据 | 位移方向、点动时长区间、滑行位移和角度差分速度。只能分析一次连续点动；不是电机力矩、电流或精密时间常数测量 |

CPR 起终点均取末 1 秒，至少需要 0.8 秒连续静态记录且计数保持不变。全程必须连续、无故障、同一原点，不能中途 D/U 或复位。当前 v1 没有原始编码器计数，软件在本次固件系数匹配、Q10 未饱和且映射可逆时恢复相对计数；角度转换值须与原始 Q10 一致，不接受界面舍入后重新填写的角度，结果明确标注“逆算”。project-v0.2.0 的 v2 已提供直接累计计数。软件不能证明未被遥测采到的板上 U 操作，仍需现场确认原点未变。

“机械人工测量与追溯信息”可记录摆臂/摆杆长度、摆杆质量、质心距转轴，以及工具、精度、条件、记录人和固件 Git 版本。尺寸、质量必须为正数，未知留空；点击“保存机械人工测量记录”可独立保存，不依赖遥测计算，也不会把人工填写值当传感器结果。

计算成功后点击“保存测量报告与原始窗口”。在采集目录的 `measurements/<时间戳>/` 中保存 `report.json` 和支持本次结果的 `samples.csv`，报告保留参数、来源、静态端点及原始窗口 SHA256；独立人工记录只有报告。来源切换、重新连接或重新 D/U 会清除旧测量窗口和端点，避免混用数据。后续设备时间、目标、观测与诊断字段在开发者模式查看；未上报保持“未提供”，没有在线参数写入功能。

## 可选串口与开发板控制日志

打开“设置 → 日志保留”，分别选择“保留串口收发日志”和“保留开发板控制日志”，点击“保存设置”。默认均关闭；连接中也可修改，保存后立即生效，下次启动保留选择。这些可选日志与自动 `fpga_logs` 和“开始实验记录”独立，只记录真实串口连接期间的事件，演示和回放不会生成开发板操作日志。

文件保存到 `captures/logs/<时间戳与会话编号>/`；窗口底部显示保留项目和当前目录，可复制路径。每次连接单独保存，两项都关闭后结束当前日志会话，再开启建立新会话；关闭期间的数据不会补录。

| 文件 | 内容 |
| --- | --- |
| `metadata.json` | 上位机版本、兼容项目基线、COM、工作模式、完整串口格式及会话开始时的日志选项；兼容基线不是自动识别出的板上固件版本 |
| `serial.jsonl` | RX 收到的原始字节、TX 串口驱动报告已写入的字节，含 HEX、字节数、UTC 和电脑单调时间；短写标明实际数量、请求数量与未完成状态。通用发送排队/拒绝及串口异常另列事件 |
| `control.jsonl` | 连接、断开、命令排队/拒绝/完整写入、标定/状态/故障变化及串口异常，附当时最新遥测上下文 |

两种日志仅在对应选项开启且出现事件时生成。RX 保留坏帧和未解析字节，可辅助分析 CRC、同步和通信异常；控制日志用于对照操作与状态，精确连续曲线仍使用实验记录。**排队、写入和遥测状态变化均不是命令 ACK**；被 S 或断开取消的命令可能只有排队记录。电脑时间也不是设备采样时间。

日志写入失败或缓存满时，底部提示记录可能不完整；控制和采集仍可继续。修复保存路径或空间后，重新保存日志选项可重试。文件按事件持续追加，异常退出可能丢失尾部；实验记录和测量报告仍须单独保存。

## 数据边界

project-v0.2.0 已标定后持续估计角速度；坏窗、标定与断流恢复期须按质量位判断有效性。旧 v1 固件停机时清速度，不等于机构静止。请求量和门控后命令均是软件量，不是实测电压、转速或力矩。约 50 Hz 遥测限制峰值与时间精度；设备毫秒计数与原始编码器计数由新固件上报，未提供的量仍明确显示“未提供”。

project-v0.1.2 及之后版本在 v1 原保留字节锁存最近启动结果和板级异常状态，host-v0.5.1 直接显示并写入运行日志，布局见 `PROTOCOL.md`。project-v0.1.3 的 2 ms 采样看门狗覆盖待机、点动和自动运行，采样超时显示 0x04，拒绝启动/点动和旧样本 D/U；状态心跳继续上报，重复的最后可信姿态不能当成新有效采样。旧v1的完整固件版本需手工记录，兼容基线不代表连接设备版本；新v2显示设备实际上报的版本ID；更新 FPGA 后需要重新 D/U 标定。

协议见同文件夹 `PROTOCOL.md`（EXE 随附名称为 `HOST_PROTOCOL.md`）；完整硬件操作与测量流程见开发机器单独维护的 `用户手册.md`，该文件不随仓库分发。

```powershell
python -m pip install PyInstaller==6.20.0

```

默认输出 `Release/host-v0.6.7/J280_Monitor.exe`。也可使用 `python tools/build_host.py --dist-dir Release/host-local-build` 输出到独立版本目录，避免覆盖正在运行的程序。构建会进行离线启动检查；该检查不代表物理串口或实物控制通过。

## project-v0.2.0 的 ADC 诊断

主面板直接显示最新捕获原码、控制均值（v0.2.4为连续整窗平均）、窗口最小/最大值、D/U端点、测量有效/就绪、坏窗和窗口/实时OTR。窗口跨越0/1023或有短OTR时，即使均值位于中间也不能视为有效。有效与就绪是设备上报状态，标定完成不等于二者已满足。设备版本ID、毫秒计数和采样窗口计数同时保存；采样计数包含坏窗。

“请求输出”与“门控后命令”分开显示，门控后也是软件指令，不是引脚实测或电流/力矩。“首次故障”保留初始原因，后续ADC异常不覆盖；S停止但保留首故障，停机D/U或R的清除语义详见协议。日志目录结构与旧版相同，新增字段写入telemetry.jsonl，G/H/F/B的按钮条件写入control.jsonl。

H仅对提供新版本和测量状态的固件开放；G/H都需要真实完成方向、盲区和范围核验后勾选确认。“未勾选”与“未标定”为不同原因，不能为使按钮可用而跳过核验。


## v0.6.1：采样故障与曲线刷新

与project-v0.2.1配合，主面板显示当前质量细因、首次传感器故障原因和触发时窗口。原码跨度警示与阻止控制的坏窗口分开显示；当前值恢复后，锁存证据仍保留。恢复连续可信采样后可在待机点击“清除故障 R”，板端条件不满足时不会清掉传感器故障，清除不会自动启动，也不丢掉标定。旧固件仍按其原有R语义处理。

实时曲线按10Hz绘制，采集、逐帧日志和命令条件仍保持接收节拍；暂停/隐藏曲线或没有新样本时不重复绘制。图形采用单像素线，全部记录仍保存，不以丢帧换取流畅。显示刷新率不是FPGA采样或遥测频率。

“保持待机”指控制器不输出电机驱动；如果机构从未动作、面板为待机且门控后命令为0，就已满足这一状态，不需要反复按停止或复位。自然下垂静止仍报传感器故障时，先保留记录，暂不做电机方向核验。

## 采样诊断使用

本版配套固件连接后应显示设备project-v0.2.8 / 0x00020008。旧版本仍可解析：v0.2.1/2为三点中值，v0.2.3为七点中值及16点控制平均，v0.2.4起为七点中值及连续整窗控制平均。主面板保留当前和首次故障摘要；扩展遥测可查看中值输出数量、总和、离群索引、事件标志及驱动标签，悬停查看单位和边界。自动`captures/fpga_logs`与CSV均保留展开字段，不需要手动抄数。

直立接管H没有独立确认框，共用“已核验方向、盲区与运动范围”，只在已标定、无故障、测量有效且近直立低速等条件下开放。自然下垂约±180°时H灰色正常。F/B每次±100‰、最多150ms用于方向与小幅响应核验，不按转角闭环控制。

本版故障统计不自动放行或重启，不以全流核对均值代替质量门禁（v0.2.4控制采用同一1ms窗的独立求和；旧版连续均值仅为旁路统计）。离群持续长度及数字边沿距离用于比较可能的干扰特征，不是模拟电路测量或PWM干扰已证实的结论。先完成自然下垂静态采集，静态正常后按本地手册做受限点动；实际平衡与起摆仍待问题定位和方向契约核验。

## 定PWM电机测试

左侧“开发板控制”下方提供定PWM测试，必要时向下滚动。完成静态采样与D/U，确认点动空间后勾选“已确认点动空间，准备按 SW3”，选择15%或22%，分别点击正向或反向测试。先用15%，每次结束并回稳后再操作；始终可用S/Esc或SW3停止。

这是固定占空比测试，不是恒速或固定转角控制。最多0.5s，±128原始计数位移上限；前0.3s完全没有编码器变化会结束。面板显示当前/最近测试原因及相对计数，自动运行日志保留状态、命令和原始反馈。运行中不接受续期或反向请求。没有第二台摆杆电机：摆杆端WDD35D4-5K是电位器。

此功能要求设备上报project-v0.2.3或相应支持版本；旧F/B仍为10%、150ms。采样、方向及负载问题尚待实物核验，七点滤波与测试模式不等于已通过自动起摆和平衡验收。


## host-v0.6.4 / project-v0.2.4

新版修正电机输出方向，G/H在启动前检查位置和速度限位，上位机显示当前值及具体拒收原因。开环F/B、J/K/L/M取消累计位置限制，保留摆臂速度及其他准入条件；固定PWM测试仍有单次0.5秒/相对128计数限制。R/S不清摆臂原点、不自动启动。位置越限后可以在故障已清、采样健康且方向已核验时，用短F/B朝零位返回；G/H须回到闭环范围内。

设备应上报project-v0.2.4 / 0x00020004。ADC采用七点中值后的完整1ms连续平均，并检查均值块跨度、步进和块内方差；过量程/轨端仍使窗口无效。199字节帧长度不变。界面按设备版本解释控制均值和16个诊断抽样范围，旧日志保留旧语义。具体依据、转角结果和验收边界见[本版说明](../docs/方向限位与连续采样修复.md)。
