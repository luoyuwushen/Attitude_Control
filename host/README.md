# J280 姿态控制测量工作站

上位机版本 **host-v0.4.0（2026-09-27）**，兼容项目/FPGA **project-v0.1.1** 基线。主界面提供现有串口控制、实时曲线、实验记录、CSV 回放和通用收发；开发者模式在同一窗口切换到测量分析页面。设置可分别保留串口和开发板控制日志。位置与观测扩展字段需要后续固件上报；硬件标定、起摆与抗扰仍需现场核验。

## 启动

Windows 本机发布包 `Project/Release/host-v0.4.0/J280_Monitor.exe` 可直接运行；同目录的 `HOST_README.md` 和 `HOST_PROTOCOL.md` 提供说明。EXE 为本地产物，不包含在源码仓库中，克隆后可按下文自行打包。源码运行时，在 `Project` 执行：

```powershell
python -m pip install -r host/requirements.txt
python tools/host_monitor.py --demo
```

依赖包括 PySide6-Essentials、pyqtgraph 和 pyserial。演示模式明确标示“非实测”，可体验曲线、截图和记录；不会发送设备命令。打开已有 CSV 可回放，支持暂停及 0.5×、1×、2×、4×速度。“冻结曲线”只暂停绘图，采集与记录继续。

## 串口设置与连接

先关闭占用同一串口的官方工具，选择核心板 CH340 的实际 COM 号。在“设置”中选择工作模式和串口参数，保存后点击“连接串口”；连接期间参数锁定，修改前须断开。

| 设置 | 支持值 | 用法 |
| --- | --- | --- |
| 波特率 | 1～4000000 的整数 | 可直接输入；点击“加入常用波特率”添加多个自定义值，保存后下次启动保留 |
| 数据位 | 5、6、7、8 | 与设备端保持一致 |
| 校验位 | N 无校验、E 偶校验、O 奇校验、M 标记校验、S 空校验 | 是否可用取决于串口驱动 |
| 停止位 | 1、1.5、2 | 是否可用取决于串口驱动 |
| 工作模式 | J280 遥测与控制、通用串口收发 | 两种模式须断开后切换 |

**当前 project-v0.1.1 FPGA 固定为 115200、8N1。** 点击“恢复 J280 默认”可恢复匹配配置；修改上位机参数不会修改 FPGA。J280 模式选用其他参数时，所有项目控制命令均禁用，包括串口停止命令；停止机构使用板上 SW3。

串口设置、常用波特率和日志开关保存在采集目录的 `host_preferences.json`；源码默认位于 `Project/Release/captures`，EXE 位于同目录 `captures`，`--output` 可指定其他目录。删除该偏好文件后，下次启动恢复默认设置并关闭日志保留；每次启动显示主界面。

“通用串口收发”提供 HEX 和文本收发，可查看官方例程或其他设备的原始数据。文本编码支持 UTF-8、GBK、ASCII，换行默认“不附加换行”，也可显式选择 LF、CR 或 CRLF；HEX 发送仅按输入字节发送，换行须写入 `0A`、`0D` 等字节。通用模式不自动发 `S`，不解析为本项目遥测；原始日志不能直接用于项目曲线和辨识。单次发送最多 4096 字节；数据位小于 8 时，超过该位宽的字节会被拒绝，避免静默截断。收发字节数可用于核对通信量；完整写入串口不等于设备执行成功。

接收默认显示 HEX，可切换文本编码。接收缓存只保留最后 256 KiB；“保存接收字节”将当前缓存保存为 `.bin`，不是无限连续记录。J280 模式也可查看原始接收，任意字节发送只在通用模式开放。

## J280 标定与运行

使用默认串口配置，收到最新有效遥测后再操作。主界面“开发板控制”提供 D/U 标定、方向核验、G 起摆与平衡、F/B 限时点动、R 清控制器故障和 S 停止。D、U、G、S 分别对应板上 SW1、SW4、SW2、SW3；**SW5 系统复位继续使用板上按键，R 不等于系统复位。** 开发者模式用于测量与分析。

1. 按 SW3 或发送 `S`，待机构停稳。摆杆自然下垂时记录 `D`。
2. 保持停机，扶至直立后记录 `U`；检查标定完成、直立角接近零。两位置须在同一连续电位器区间。
3. 核验角度、编码器与电机方向、盲区和运动范围，确认后在主界面勾选核验项。`G/F/B` 均要求已标定、待机、无故障及完整核验；`F/B` 为 10% 控制指令、最多 150 ms 点动，不连续续期。开发者模式可分析测量结果；首次电机方向核验的操作路径仍需完善，不能用虚假勾选跳过核验。
4. 从自然下垂发送 `G` 自动起摆。点击停止或按 `Esc` 发送 `S`；异常时使用板上 SW3。

仅 J280 模式且配置为 115200、8N1 时，默认断开或退出尝试发送 `S`，串口故障时不能保证收到。先确认机构停止再关闭；旧命令行 `telemetry_monitor.py` 退出不会自动发 `S`。命令没有 ACK，“已写入”不代表执行成功，应检查遥测反馈。重新上电、复位或下载后需要重做 D/U。

## 实验与记录

“开始实验记录”可填写名称、板号、固件 Git 版本、方向参数、实测单圈计数、安装与测试条件；未知项留空。默认保存到 `Project/Release/captures/session_*`，EXE 移动后保存到其同目录的 `captures`；可用 `--output` 指定目录。

每次记录包含 `metadata.json`、`samples.csv`、有效原始帧 `raw_frames.bin`、事件 `events.jsonl` 和结束时生成的 `summary.json`。主界面可添加人工标记、保存曲线 PNG；在开发者模式的“实验指标”页查看分析结果，轻推撤手后点击该页“标记扰动结束”，按所设角度带和连续保持时间判断恢复。默认 ±2°、0.5 秒是项目参考标准，手推不是已测力矩。

CSV 同时保存四个状态量的原始 Q10 与转换值。指标包括首次捕获时间、捕获次数、平衡 RMS/偏置/峰值、最长连续平衡及 ±2° 保持时间、摆臂范围，以及起摆/平衡限幅比例；平衡与恢复只使用明确已标定、无控制器故障的样本。缺帧和长接收间隔会打断连续保持判断。回放要求有效样本在同一时间列上有有限时间值，时间缺失会提示错误；再次记录、回放仍保留最初的演示或实测来源。

## 开发者模式：补齐待测数据

点击“设置 → 进入开发者模式”，当前窗口切换到测量页面，提供“实测与辨识”“实验指标”“扩展遥测”三页。点击顶部“返回主界面”恢复控制页面；切换不重连串口、不清空数据、不停止实验记录或日志。两个页面顶部始终提供停止 S，Esc 同样可用。进入开发者模式不会保存设置中尚未提交的修改，需先“保存设置”再进入。

在“实测与辨识”选择测量项目和“当前数据窗口”（1～120 秒），采集后点击“计算当前窗口”。演示与回放保留来源标识，演示结果不会标成实物测量，回放不代表本次现场实测。串口数据过期时不能继续计算；丢帧、重复、复位、时间倒退或超过 100 ms 的接收间隔会拒绝连续辨识。修改计算参数后需重新计算再保存。

| 测量项目 | 操作 | 输出及边界 |
| --- | --- | --- |
| ADC 静态噪声 / 标定辅助 | 停机并保持静止；下垂、直立各保持至少 1 秒后保存末 1 秒静态段，再计算 | ADC 均值、标准差、范围；已标定且无故障时附角度噪声。保存静态段只记录数据，不发送 D/U；整数 ADC 遥测不是内部 Q4 标定寄存器 |
| 编码器单圈 / 已知角度计数 | 填入本次固件 `COUNTS_PER_REV`、`ENCODER_SIGN`；停机且已标定，记录稳定起点，手动转过独立测得的角度后记录稳定终点，填入带方向的实际转角，默认 0 不可用于计算 | 计数差与 CPR 估计。可用安全的小角度，不必强行转满一圈；不能把软件显示的 360° 当机械参考 |
| ADC 有效区 / 疑似盲区扫描 | 停机，缓慢手动扫描，选择覆盖扫描的窗口；可在未标定的待机状态采集；默认相邻跳变阈值为 32 码 | ADC 范围、近电压轨及跳变/故障采样点。须结合机械参考与录像定位，不能单凭跳变得到盲区角度或电气行程 |
| 下垂自由衰减 | 完成标定，固定摆臂；摆杆偏离下垂约 5～10° 后轻轻释放，保留至少 4 个同侧峰；可填写已测静态角度噪声 | 衰减周期、振幅衰减率、归一化 `b/J` 和 `mgd/J`。整段须在下垂 ±15° 内，摆臂变化默认不超过 2°；拟合不满足条件时不输出。不能由此得到绝对惯量、绝对阻尼或质量 |
| 点动 / 滑行响应 | 在主界面满足核验条件后进行一次 F/B 限时点动，再进入开发者模式分析；窗口包含点动前后各至少 3 帧待机数据 | 位移方向、点动时长区间、滑行位移和角度差分速度。只能分析一次连续点动；不是电机力矩、电流或精密时间常数测量 |

CPR 起终点均取末 1 秒，至少需要 0.8 秒连续静态记录且计数保持不变。全程必须连续、无故障、同一原点，不能中途 D/U 或复位。当前 v1 没有原始编码器计数，软件在本次固件系数匹配、Q10 未饱和且映射可逆时恢复相对计数；角度转换值须与原始 Q10 一致，不接受界面舍入后重新填写的角度，结果明确标注“逆算”。未来 v2 上报累计计数后可使用直接计数。软件不能证明未被遥测采到的板上 U 操作，仍需现场确认原点未变。

“机械人工测量与追溯信息”可记录摆臂/摆杆长度、摆杆质量、质心距转轴，以及工具、精度、条件、记录人和固件 Git 版本。尺寸、质量必须为正数，未知留空；点击“保存机械人工测量记录”可独立保存，不依赖遥测计算，也不会把人工填写值当传感器结果。

计算成功后点击“保存测量报告与原始窗口”。在采集目录的 `measurements/<时间戳>/` 中保存 `report.json` 和支持本次结果的 `samples.csv`，报告保留参数、来源、静态端点及原始窗口 SHA256；独立人工记录只有报告。来源切换、重新连接或重新 D/U 会清除旧测量窗口和端点，避免混用数据。后续设备时间、目标、观测与诊断字段在开发者模式查看；未上报保持“未提供”，没有在线参数写入功能。

## 保留串口与开发板控制日志

打开“设置 → 日志保留”，分别选择“保留串口收发日志”和“保留开发板控制日志”，点击“保存设置”。默认均关闭；连接中也可修改，保存后立即生效，下次启动保留选择。日志与“开始实验记录”独立，只记录真实串口连接期间的事件，演示和回放不会生成开发板操作日志。

文件保存到 `captures/logs/<时间戳与会话编号>/`；窗口底部显示保留项目和当前目录，可复制路径。每次连接单独保存，两项都关闭后结束当前日志会话，再开启建立新会话；关闭期间的数据不会补录。

| 文件 | 内容 |
| --- | --- |
| `metadata.json` | 上位机版本、兼容项目基线、COM、工作模式、完整串口格式及会话开始时的日志选项；兼容基线不是自动识别出的板上固件版本 |
| `serial.jsonl` | RX 收到的原始字节、TX 串口驱动报告已写入的字节，含 HEX、字节数、UTC 和电脑单调时间；短写标明实际数量、请求数量与未完成状态。通用发送排队/拒绝及串口异常另列事件 |
| `control.jsonl` | 连接、断开、命令排队/拒绝/完整写入、标定/状态/故障变化及串口异常，附当时最新遥测上下文 |

两种日志仅在对应选项开启且出现事件时生成。RX 保留坏帧和未解析字节，可辅助分析 CRC、同步和通信异常；控制日志用于对照操作与状态，精确连续曲线仍使用实验记录。**排队、写入和遥测状态变化均不是命令 ACK**；被 S 或断开取消的命令可能只有排队记录。电脑时间也不是设备采样时间。

日志写入失败或缓存满时，底部提示记录可能不完整；控制和采集仍可继续。修复保存路径或空间后，重新保存日志选项可重试。文件按事件持续追加，异常退出可能丢失尾部；实验记录和测量报告仍须单独保存。

## 数据边界

角速度来自 FPGA 估计，停机时被清零，不能据此判断手动运动静止。控制量是 PWM 请求，不是实测转速或力矩。当前约 50 Hz 遥测限制峰值与时间精度；缺帧处曲线断开。当前固件不提供原始编码器计数、设备时间、标定寄存器及观测结果，扩展页显示“未提供”；故障零也不排除未上报的底层异常。

协议见同文件夹 `PROTOCOL.md`（EXE 随附名称为 `HOST_PROTOCOL.md`）；完整硬件操作与测量流程见开发机器单独维护的 `用户手册.md`，该文件不随仓库分发。

## 自行打包

在 Windows 的 `Project` 目录执行：

```powershell
python -m pip install PyInstaller==6.20.0
python tools/build_host.py
```

默认输出 `Release/host-v0.4.0/J280_Monitor.exe`。也可使用 `python tools/build_host.py --dist-dir Release/host-v0.4.0` 输出到独立版本目录，避免覆盖正在运行的程序。构建会进行离线启动检查；该检查不代表物理串口或实物控制通过。
