# J280 上位机遥测协议

串口为 115200 bps、8N1。多字节数值均为小端。项目 FPGA 0.1.1 仅发送 **v1**，约 50 Hz；上位机 0.2.0 同时具备 v2 解码预留，不改变现有 RTL。

## v1：固定 24 字节

| 字节偏移 | 长度 | 字段 | 格式 / 含义 |
| --- | --- | --- | --- |
| 0 | 2 | 帧头 | `AA 55` |
| 2 | 1 | 版本 | `01` |
| 3 | 1 | 总长度 | `18`（24） |
| 4 | 2 | sequence | uint16，已发送快照序号 |
| 6 | 2 | adc | uint16，10 位采样均值整数码 |
| 8 | 2 | theta | int16，Q10 rad，直立为零 |
| 10 | 2 | omega | int16，Q10 rad/s，估计摆杆角速度 |
| 12 | 2 | arm | int16，Q10 rad，直立标定时摆臂位置为零 |
| 14 | 2 | arm_speed | int16，Q10 rad/s，估计摆臂角速度 |
| 16 | 2 | command | int16，PWM 请求千分比 |
| 18 | 1 | state | 0 待机、1 起摆、2 平衡、3 故障、4 点动 |
| 19 | 1 | calibrated | bit0：两点标定是否完成 |
| 20 | 1 | fault | 控制器故障位，见下表 |
| 21 | 1 | 保留 | 当前为 0 |
| 22 | 2 | CRC | CRC-16/CCITT-FALSE，覆盖 0～21 |

CRC 初值 `FFFF`、多项式 `1021`，无反射、无最终异或，低字节先发。Q10 转 rad 或 rad/s 时除以 1024，角度显示再乘 180/π。

| 故障位 | 含义 |
| --- | --- |
| `01` | 传感器 / 接口异常 |
| `02` | 标定失效 |
| `04` | 有效采样看门狗 |
| `08` | 位移 / 速度超限 |
| `10` | 起摆超时 |
| `20` | 平衡跌落 |

命令为单个 ASCII 字节 `D/U/G/S/R/F/B`，不要求换行、没有 ACK。详细操作条件见使用手册。序号在接受发送快照时递增，不能诊断 FPGA 忙时丢弃的触发；上位机对倒序作重启/倒序启发式诊断，不等同于设备确认重启。

## v2：上位机预留

帧头为 `AA 55 02 length`，偏移 4～21 沿用 v1。偏移 22 开始追加 TLV，最后两字节为 CRC，覆盖此前全部字节。`length` 是含 CRC 的总长度，范围 24～255。每项为 `type:uint8 + value_length:uint8 + value`。已知类型重复、长度不符、截断或非有限浮点值会被拒绝；未知类型按长度跳过，原始帧仍保留。

| type | 字段 | value 字节数 / 格式 | 单位 / 转换 |
| --- | --- | --- | --- |
| 1 | device_time_ms | 4 / uint32 | ms |
| 2 | encoder_count | 4 / int32 | 累计计数 |
| 3 | target_arm_deg | 2 / int16 Q10 | rad 转 ° |
| 4 | target_speed_rad_s | 2 / int16 Q10 | rad/s |
| 5 | observer_theta_deg | 2 / int16 Q10 | rad 转 ° |
| 6 | observer_confidence | 4 / float32 | 置信度，约定 0～1 |
| 7 | energy_error | 4 / float32 | 归一化能量误差 |
| 8 | parameter_version | 4 / uint32 | 参数版本 ID |
| 9 | control_loop_us | 2 / uint16 | μs |
| 10 | sensor_flags | 2 / uint16 | 位定义待固件确定 |
| 11 | adc_down | 2 / uint16 | 标定码，量纲须与未来固件确定 |
| 12 | adc_up | 2 / uint16 | 标定码，量纲须与未来固件确定 |

目前 RTL 未支持 v2，缺失字段不会补零。目标设置、在线调参及辨识命令也未实现。115200、8N1 的理论字节率为 11520 B/s，不能直接传输全部 1 kHz 控制帧；未来扩展需核算负载并选择字段或降采样。
