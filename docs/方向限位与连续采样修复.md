# 方向、运动限位与连续采样

适用版本：project-v0.2.4 / host-v0.6.4。实物起摆、持续平衡与抗扰尚未验收。

补充官方对照：用户已确认从两侧扶到直立后再按官方SW1均能平衡；这不代表手扶途中ADC始终有效。当前待机也锁存轨端/OTR，恢复后按R再H的条件、原码与算法的区分见[双向手扶与ADC轨端](双向手扶与ADC轨端.md)。

## 现场问题与证据

2026-09-28 的三段串口会话共 21457 帧，原始 CRC、序号和设备时间连续。问题分为三类：

- 连续正向测试后摆臂累计越过 ±6 rad 位置限制。板端拒绝继续运动，待机故障却可为零，上位机没有说明当前限位，表现为按钮可点但电机不动。R 不改变编码器原点。
- 三次手扶直立均先进入平衡，再发生 0x20 跌落；轨端/OTR 传感器故障在其后出现。正输入在各次受限测试中实际产生负编码器位移，和控制模型的输入方向相反。近静止下垂测试显示两测量坐标之间的耦合关系与模型一致，支持只翻转电机输出符号。
- 一次自动起摆首先出现独立的采样故障：中值窗口跨度 33 code，而 5000 个中值结果仅 5 个相对前窗超过 16 code，控制均值仍稳定在约 220.4。原判据把短时极差直接当成整窗不可信；控制均值又只稀疏取 16 点，缺少对连续转换的完整利用。

02:47 会话另有一次最大 3.227 秒的界面交付积压，发生在首次电机测试之前。串口线程仍接收，无法由日志唯一定位卡顿来源。其余两段最大交付延迟约 33/26 ms；不能把板端位置拒收解释为串口死机，也不能由此宣称所有界面卡顿已解决。

## 输出方向与准入

默认参数改为 `THETA_SIGN=+1`、`ENCODER_SIGN=+1`、`MOTOR_SIGN=-1`。控制正输入经过符号映射后，应使原始编码器计数增加；这项预期需要首次短点动复核。标定方式、引脚映射、LQR/起摆增益和名义编码器 1040 count/rev 保留。1040 仍不是本件实测结果。

G/H 在进入运行之前检查与运行中相同的绝对位置和速度条件。上位机使用原始 Q10 值镜像门限，显示具体越界数值并禁止相关按钮，S/R 仍按其停止/恢复规则工作。

官方 `Interface_test` 持续定 PWM 不检查累计编码器位置；±6 rad 是本工程的闭环软件限制，不是套件的硬件旋转极限。本版将开环测试与闭环限位分开：F/B、J/K/L/M 不再因累计转过一圈而拒收，也允许在闭环位置限外做已核验方向的受限测试；其速度、采样、停止与单次动作限制继续生效。

| 条件 | G/H | F/B、J/K/L/M |
| --- | --- | --- |
| 摆臂位置绝对值 >6144 Q10（6 rad） | 拒收 | 不限制累计位置 |
| 摆臂速度绝对值 >20480 Q10（20 rad/s） | 拒收 | 拒收 |
| 摆杆速度绝对值 >30720 Q10（30 rad/s） | 拒收 | 不新增此限制 |

H 还保留近直立、低速接管要求。边界等于门限仍按原规则允许；方向核验、有效成熟采样、标定与故障条件继续生效。R/S 不重设坐标，不自动恢复运动。

## 连续均值与质量判定

ADC 仍为 5 MHz 整总线固定相位捕获及七点中值。控制 Q4 均值改用一个 1 ms 窗口内的全部连续中值结果，按实际转换数量精确舍入；默认窗口为 5000 个输出。诊断计数/总和的饱和设置不参与控制计算。均值、坏窗、原码证据和转换统计作为同一窗口发布。

在默认 5000 转换窗口中，以短块分别检查均值变化和块内离散程度，避免仅凭一次中值极值否决稳定窗口，同时防止“高低异常恰好平均成合理数值”。质量位和完整时序见[协议](../host/PROTOCOL.md)与[技术文档](../开发项目技术文档.md)。单级整窗平均不是理想抗混叠滤波器，不能承诺滤除所有干扰。

原始 OTR 和原码 0/1023 继续绕过中值、均值，任一转换越界都会使对应窗口不可信。相邻控制均值突变、采样超时、角度映射和标定保护保留；不能用平均掩盖电位器盲区或持续噪声。

遥测仍为 199 字节、约 50 Hz，不进一步增加 115200 串口负载。固件身份为 `0x00020004`，主机对历史版本保留原解释。原 `contribution_min/max` 在新版仅表示原有 16 个诊断抽样点，控制已使用完整转换流；原中值极值、计数、总和、离群和来源标签继续保持其含义。

## 定 PWM 测试与后续验收

15%/22% 测试用于比较驱动响应，不能控制恒速或固定转角。达到 ±128 原始计数或 0.5 秒时撤销驱动，高阻停止仍可能滑行。本次最后一段测试在停止后约一秒观察到的名义转角为：

| 测试 | 各次转角绝对值（含滑行） |
| --- | --- |
| 15% 正向 | 69.2°、56.8°、57.1° |
| 15% 反向 | 63.3°、78.6°、72.7° |
| 22% 正向 | 94.2°、80.0° |
| 22% 反向 | 108.7°、76.2° |

测试前检查实际线缆和运动空间，不把±6 rad当作硬件极限。G/H位置越限时，先停止驱动、待停稳后沿原路径返回原标定摆臂零位附近；已核验方向时可用短 F/B 朝零位移动，也可手动返回，不通过重新 U 掩盖累计位移。新版首次验证从短 F/B 方向检查开始，再做 H 直立接管；H 保持与轻推恢复通过后再验收 G 自动起摆。具体操作以本地用户手册为准。

赛题基础要求仍是自然下垂自动起摆、持续直立、捕获后少震荡和轻推后恢复。离线测试和生成位流只能验证逻辑与构建，不能替代这些实物结果。
