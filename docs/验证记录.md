## 上位机 host-v0.4.1 长时显示修复（2026-09-27）

旧版终端满256KiB缓存后，每次追加HEX均可触发近80万字符全量重排。只读离线同口径对照中，5次48字节刷新中位耗时旧版426.21ms、修复初版0.13ms；旧版均调用全量render，修复版为0次。40ms GUI刷新周期不足以处理旧路径，CRC及序号连续并不排除遥测交付积压。该对照是本机性能证据，不是串口设备测量。

修复将原始缓存和文本显示分别限制大小，HEX短行增量追加、模式切换只重建末段，并保留跨包文本解码及完整Unicode字符裁剪。原始缓存导出逐字节等于输入末256KiB。5项新增回归包含750秒、50Hz等量24字节帧输入（加速离线、未打开串口），满缓存持续追加、显示切换后短行、原始字节保存、无换行文本和UTF-8/UTF-16边界。

全套149项软件测试通过，无跳过。官方资料31/31、工程14文件与29管脚核验通过，原位流及构建证据验证通过；本次未改RTL、CST或SDC。Windows修复包的构建、自检、校验值见 `host_validation.json`。实板超过原故障时长的连续采集仍待用户复验；未将本次修复作为SW2不起摆已解决的证据。

## 指定模型的真实 RTL 闭环

机械假设及标称电机参数见技术文档和 `tools/control_model.py`。传感器有效跨度约 338 原始码，16 次瞬时 10 位量化求和；编码器按 1040 counts/rev 量化。示例下垂电气相位为 210°，`THETA_SIGN=-1`，下垂/直立原始码为 717/541。

| --- | --- |
| 仿真长度 | 12.000 s |
| 首次捕获时间 / 捕获次数 | 0.769000 s / 1 |
| 结束倾角 | -0.273889° |
| 最后 2 s 最大绝对倾角 | 0.687076° |
| 扰动 | 2.000～2.050 s，模型摆杆力矩 0.01 N·m |

| 摆臂最大绝对位置 | 1.716154 rad |

闭环测试每个虚拟 1 ms 使用 1000 个仿真时钟，PWM、死区、采样及动力学积分保持对应的相对节拍。ADC 和编码器向估算器输入量化数据；物理采集引脚的逻辑由独立接口和顶层自检覆盖。该测试没有模拟线路传播、齿隙、限流或温升，不能称为实物 HIL。工程默认符号为 +1；模型示例符号不能代替现场方向测量。不利安装相位的 Python 负例验证了跨盲区后保护停机。

±2°、500 ms 和测试时长是内部检查标准，赛题没有规定这些数值。
