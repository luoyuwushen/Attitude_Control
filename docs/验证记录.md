# v0.1.0 验证记录

验证日期：2026-09-26。硬件目标为官方 J280 开发板和倒立摆套件；本记录包含资料校验、软件/RTL 仿真和真实 Gowin 构建，不包含实物运行结果。

## 环境与复现

Python 3.12.5、NumPy 1.26.4、SciPy 1.17.1；Icarus Verilog 12.0 (devel)；Gowin V1.9.12.03 (64-bit)。执行：

```powershell
Set-Location "E:/workplace/Gowin/Attitude_Control/Project"
python tools/run_tests.py --iverilog .tools/iverilog/bin
python tools/build.py --gw-sh "E:/gowin_std_probe/Gowin_V1.9.12.03_x64/IDE/bin/gw_sh.exe"
```

`.tools` 为本机工具，不随源码分发；其他机器安装 Icarus 后指定实际目录。串口工具依赖 pyserial，物理串口待现场验证。

## 指定模型的真实 RTL 闭环

机械假设及标称电机参数见技术文档和 `tools/control_model.py`。传感器有效跨度约 338 原始码，16 次瞬时 10 位量化求和；编码器按 1040 counts/rev 量化。示例下垂电气相位为 210°，`THETA_SIGN=-1`，下垂/直立原始码为 717/541。

| 指标 | 仿真结果 |
| --- | --- |
| 仿真长度 | 12.000 s |
| 首次捕获时间 / 捕获次数 | 0.769000 s / 1 |
| 结束倾角 | -0.273889° |
| 最后 2 s 最大绝对倾角 | 0.687076° |
| 扰动 | 2.000～2.050 s，模型摆杆力矩 0.01 N·m |
| 扰动后峰值绝对倾角 | 2.790448° |
| 扰动结束后的恢复时间 | 0.353000 s，进入 ±2° 且连续维持 500 ms |
| 摆臂最大绝对位置 | 1.716154 rad |

闭环测试每个虚拟 1 ms 使用 1000 个仿真时钟，PWM、死区、采样及动力学积分保持对应的相对节拍。ADC 和编码器向估算器输入量化数据；物理采集引脚的逻辑由独立接口和顶层自检覆盖。该测试没有模拟线路传播、齿隙、限流或温升，不能称为实物 HIL。工程默认符号为 +1；模型示例符号不能代替现场方向测量。不利安装相位的 Python 负例验证了跨盲区后保护停机。

±2°、500 ms 和测试时长是内部检查标准，赛题没有规定这些数值。
