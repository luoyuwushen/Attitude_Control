# v0.2.8 实测：标定零点、H 余振与 G 回摆故障

2026-09-28，现场会话 `20260928_194347_282262_124ffb96`，配套 host-v0.6.7。H 已松手保持约29.62秒，由 S 主动结束；用户确认立即松手、全程未触碰。摆臂幅度继续减小，但仍有持续周期运动，尚未达到少振荡长期平衡。

**下一次保留当前 FPGA v0.2.8 和上位机 v0.6.7，先固定物理竖直参照重新 D/U，再做 H 对照。此次不继续提高速度增益、不扩大积分限幅，也不翻转电机方向。**

## H 的改善与代价

按共同5～29秒范围内完整周期的同一提取方法：

| 指标中位数 | v0.2.7 | v0.2.8 |
| --- | ---: | ---: |
| 摆臂峰峰值 | 103.46° | 94.48° |
| 周期 | 2.34 s | 2.25 s |
| 摆杆角标准差 | 4.02° | 3.84° |
| 控制请求 RMS | 127.47‰ | 140.91‰ |

臂幅再减约8.7%，同时输出 RMS 增约10.5%；不能只据臂幅判断全面改善。摆臂角仍按名义1040 counts/rev换算，尚不是独立机械转角测量。本次前约10秒中心重新收敛，后段均值接近H捕获参考，日志不支持一直朝一个方向漂走。

进一步排除前10秒居中过程，两段共同10～29秒各7个完整周期：臂幅中位103.85°→94.11°，摆杆角标准差4.035°→4.055°，请求RMS129.34‰→135.21‰。因此后段摆杆波动没有改善，不能把上表包含过渡过程的标准差降低当作稳定性已改善。

H共1481帧，均无故障，请求与四状态反馈、积分量化区间及软件电机方向逐帧一致。首次待机出现在144460ms，随后144729ms才保存ADC异常窗、144740ms首次遥测可见故障；它不能作为H结束原因。

## 本次 U 零点改变，占用了积分余量

两次U显示的整数值由782变为793，用户确认主要凭目测手扶直立。由当前已知RTL与全部H帧反推，旧、新等价映射分别为：

```
v0.2.7: theta_q10 = floor((12518 - adc_mean_q4) * 367 / 1024)
v0.2.8: theta_q10 = floor((12698 - adc_mean_q4) * 360 / 1024)
```

所有1468/1481帧精确匹配。上述是代码与记录反推的内部等价映射，不是物理竖直点测量；下垂端点Q4低位仍不能唯一恢复。

在共同10～29.34秒内：

| 量 | v0.2.7 | v0.2.8 |
| --- | ---: | ---: |
| ADC均值，原码单位 | 773.892 | 773.281 |
| 面板摆杆角均值 | 2.694° | 6.375° |
| 积分均值 | 39.17‰ | 94.33‰ |

把本次完全相同的ADC序列代入上次映射，角度均值为2.890°；约3.485°的差异仅由标定映射产生。它使角度反馈多出约54‰的偏置量，与积分均值增加约55‰量级相近。新H还在21.78～21.92秒出现8个可见帧的积分100‰上限，旧H没有。

这解释了本次积分余量为何明显变少，也说明两次实测不是严格的单参数A/B。**它不能证明全部周期晃动由标定造成**：上次未触积分上限时已经存在持续往返。也不能把动态平衡时ADC均值约773直接设成新的U；该均值受到运动影响，不是独立的物理竖直基准。

当前两点标定检查的是输入健康和端点跨度，软件没有另一个独立姿态传感器判断手扶位置是否真正竖直。“标定完成”和刚U后显示0°只说明该位置已被定义为零。较稳定地扶在错误角度，仍会得到稳定但偏移的零点；单纯延长ADC平均时间不能解决这一点。

## G 是回摆越界，并非初始驱动直接冲向零端

G首个运行帧为152640ms：请求+667‰、方向映射后命令−667‰，ADC约222。此后ADC先上升到约431，摆杆已沿连续有效侧抬起。到152920ms附近，泵能控制换向，摆杆回落；ADC随后约为237、168、100。

153071ms保存的首异常窗为原始范围0～83、滤后均值63.4375码，细因0x23，含原始OTR和轨端。中值均值仍非零，但该窗已因原始异常无效。153080ms首次遥测FAULT/0x01，此时当前窗口又恢复到非轨端；之后153100/153120ms才持续为0，153140ms为1023。最早引脚关断可能由实时OTR更早触发，不能把保存时刻冒充精确关断时刻。

这与此前G故障路径相似。v0.2.8只改H反馈，G泵能及其捕获参数没有变。现有G逻辑允许通过下垂点继续向另一侧摆动，**没有把本套件实际连续ADC范围作为轨迹约束**；到异常后才撤销驱动，机构仍会因惯性继续运动。这个设计缺口需要修正，不能靠反转总电机方向、取消0x01或增大起摆脉冲代替。

首个短原始异常究竟来自接近量程、模拟瞬态还是采样扰动，现有记录仍不能唯一分辨。轨迹约束针对已观察到的后继越界风险，不能据此承诺所有短OTR都会消失。

后续G需在可信角度范围内设计起摆轨迹，并在捕获后衔接经过实物验收的平衡控制。现有名义G模型的安装相位与现场不同，不能用旧模型通过来证明实际跨轨端过程可用。本阶段仍先完成H，暂不连续尝试G/SW2。

## 本次操作

1. 沿用 v0.2.8 / host-v0.6.7，无需重新烧录。先S/SW3撤销驱动；在实时ADC和窗口恢复健康、测量就绪后用R清除已有故障。
2. 机构停止后将摆臂返回原来的位置附近，检查线缆余量。让摆杆自然下垂，利用其静止轴线建立一条经过转轴的固定竖直参照线，然后D。
3. 固定摆臂位置，从正对摆杆运动平面的视角，将手扶直立的杆轴线与同一参照线对齐，扶稳约2秒再U。不要只根据面板“角度为0”判断物理直立，也不要追着历史ADC数值标定。
4. U后保持位置。接线、安装和方向未变，无需重复点动；使用已完成的方向/范围核验确认，保持直立低速后按H，立即松手。先记录10～15秒，再S结束；明显恶化或故障时提前停止。
5. 正常断开并保留完整自动日志。先不加推力、不按G/SW2；先比较标定一致后周期幅度、中心和积分余量，再延长保持。

两次已确认的早期H记录还显示：低频编码器位移与估速链基本自洽，但50Hz快照无法唯一恢复中间的1kHz状态与命令。若固定标定后仍无法确定快变输出来源，应补充有限长度1kHz观测，再决定估速或控制结构调整，而不是继续叠加未经区分的参数变化。
