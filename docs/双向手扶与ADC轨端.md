# 双向手扶接管与 ADC 轨端

适用：project-v0.2.4 / host-v0.6.4。本说明区分手扶过程的测量范围、直立接管条件与实际平衡能力。

当前验收范围为H手扶直立接管与松手平衡，自动起摆安排在此后。本阶段不发送G或按板上SW2。

## 官方对照能说明什么

用户补充：同一硬件、接线与安装位置，官方 `PID_Control.fs` 从顺时针或逆时针扶至直立后，再按 SW1，均能松手平衡。这证明两个手扶路径最终都能到达官方控制器可用的直立工作点。它没有提供途中水平位置的原始 ADC/OTR，因此不能据此认定途中从未触及测量边界。

随后用户进一步提供官方Interface_test配套串口工具的观察：自然下垂约1010，顺时针至水平接近低端，再往上跳至4300多，最终直立约3000；反方向则由约1000连续增至3000。这说明低端到高端的跳变也出现在官方采集链路，不能将跳变本身归为本项目独有的ADC算法错误。数值来自现场口述，尚无该次官方原始串口帧。

可读官方源码对16点平均后的原码先乘4再加135，稳定值1010约对应原码219，3000约对应716。该源码的理论输出范围为135～4227，因此口述“0、4300多”不能被强行当成精确匹配；工具显示处理、所烧官方接口位流与源码版本、瞬态及读数精度需由原始帧区分，也不能将官方直立约3000与本项目另一次会话U=789当作同次精密对照。当前可确认的是轨迹趋势相似，不能据此证明两套采样逐码一致。

官方 PID 只有位流，没有源码，不能推断其待机故障策略。可读的官方 `Interface_test` 使用25MHz ADC时钟、16点平均与显示缩放，不采集OTR，也没有本工程的采样故障锁存；它与PID位流不是同一算法。当前项目用5MHz固定相位捕获，并在待机也记录异常。这些差异必须分别验证，不能从“官方能平衡”直接推出哪一种采样相位有错。

## 原码零值与角度算法分开判断

当前数据链为：`adc_data_in → captured → raw_code → 遥测adc_raw → 上位机`。除复位外，`captured`只取外部10位总线；D/U、角度正负号、PID/LQR和故障状态均不会把原码强制改成0。滤波、质量判据和角度换算在它之后工作。换控制增益不能直接修复原始码为0的问题，但采样时序、总线或实际模拟输入仍需实物证据区分。

官方两份接口约束的10位数据、CLK和OE球位与当前工程逐项一致，OE均保持低电平；官方数据脚上拉与当前无上下拉、25MHz与5MHz时钟是实际差异，尚无证据证明它们导致固定机械位置的轨端跳变。本版不据此盲改引脚或采样边沿，也不移除轨端/OTR保护。

3PA1030输出为普通无符号二进制，并提供独立的越界指示。单个0/1023原码与OTR是不同证据；本项目对轨端码另加了质量保护，不能将软件轨端判据都称为芯片已报告过量程。芯片行为依据[3PEAK数据手册](https://static.3peak.com/res/doc/ds/Datasheet_3PA1030.pdf)。

最新02:53会话标定为下垂222、直立789，相差567码。若按现有两点线性模型，从下垂向标定的反方向外推90°，预测值为 `222−567÷2=−61.5`，超出10位原码范围；该模型约在反向70.5°到达零。这与用户描述“接近水平出现0”相容，**只是由标定端点得到的模型推算，不是对模拟电压、机械盲区或采样正确性的测量证明**。两点标定只证明选定半圈的映射，不能证明整个圆周连续可观测；0/1023也不能未经验证就当作角编码器的循环边界做取模。

## 当前版本如何从任一侧手扶接管

下载新版后先完成D/U与短F/B方向核验。以下步骤适用于已标定、未在运行的系统：

1. 按S或SW3停止输出，再手扶到直立标定位置。途经轨端可能留下0x01记录，不要在该位置启动，也不需要用U重设原点。
2. 在直立处保持稳定，查看实时OTR和窗口OTR均为0、样本异常为否、测量有效和已就绪均为是。若这些条件持续不满足，当前测量问题尚未恢复，不能进入下一步。
3. 若故障仍锁存，按R。当前版本只在新鲜、连续可信且成熟的测量下清除采样锁存，保留D/U与摆臂原点；清除后不会自行启动。
4. 保持近直立、低速且摆臂在闭环位置范围内，完成方向确认后按H“直立接管”。SW2/G用于自动起摆，与官方SW1的操作含义不同。

R被拒绝时，应按当前采样/停止/状态提示定位，不能反复清除持续异常。现有专项已验证“异常锁存→采样恢复→显式R→保留标定→新H才启动”及持续OTR禁止清除；这验证的是软件控制路径，不是实物平衡成功。

## 自动起摆仍需的证据

手扶到直立后接管与从下垂闭环自动起摆是不同验收项目。G需要整个实际运动轨迹上的角度/速度可用；若轨迹含真实模拟饱和或不可观测区，简单取消保护、维持旧角度或对0/1023取模都会失去可靠反馈。先验证直立邻域的采样、反馈方向、H保持及轻推恢复，再依据两侧缓慢手扶的原码/OTR日志确定可观测范围，不能把本版整窗滤波宣称为已经修复轨端或自动起摆。
