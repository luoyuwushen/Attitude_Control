# 短扰动滤波与电机测试

适用版本：project-v0.2.3 / host-v0.6.3。

## 本次实物证据

两份01:46/01:48会话共10902帧，串口记录连续。标定和多数点动正常，两次H实际进入平衡后故障，三次G获准后也很快故障；另有一次F被相同传感器故障提前中止。6个首故障窗口的5000个三点中值输出中仅1～3个离群，最长连续1～2点，滤后极差33～38码，而16贡献点极差3～12码。详见[现场核查](../Release/host-v0.6.2/validation/field_0146_0148.md)。

直接触发链是三点中值未滤除极短异常，整窗任意极值跨度超过32码即锁存。设计把短扰动与持续不能信任的测量混作同一种情况。均值正常不能单独证明整窗健康，但新增连续统计支持先改善短扰动过滤。接近数字驱动边沿只是相关证据，不能据此唯一判定模拟电路根因。

## 采样处理

保留5MHz时钟、并行总线捕获相位、每1ms的16点控制平均；将三点中值改为七点中值。七个原始值经寄存比较网络排序，取中间值，并携带该原始转换的数字驱动标签。它能剔除任一七点窗内最多三个偏离正常码值区间的转换。持续偏移、滤后整窗跨度或相邻步进超过32仍拒收；原码0/1023和OTR继续旁路硬保护。

七点窗的中心延迟约0.6μs，寄存排序结果在捕获后160ns消费；完整测量链还包含ADC自身流水及1ms平均，前两项不是端到端延迟。时间、数据及来源须由独立模型核验。旧日志只记录三点中值统计，不能精确重放每个原始转换，因此不把合成脉冲测试当作这六个实际故障已消失的证明。

新版TLV26/27仍为34字节，filtered、step、outlier及sum/count现在描述七点中值输出；旧project-v0.2.1/v0.2.2记录仍按三点解释。基准仍是上一完成窗口，参考存在不代表健康；最长序列也不等同于模拟毛刺宽度。

## 电机与官方例程

套件只有一台主动减速电机驱动摆臂。摆杆端是WDD35D4-5K导电塑料电位器，测量摆杆角度；摆杆由机械耦合运动。官方介绍资料的系统框图及传感器三线接口与此一致。XH1/XH2是控制板上的两组电机接口，不能据此推断套件存在第二台摆杆电机。

官方Interface_test的实际构建使用5400拍PWM周期与1200拍有效宽度，50MHz下约9.259kHz、22.22%占空比。编码器只用于显示，没有速度反馈，所以是固定PWM测试，并非闭环匀速。其实际综合网表让A/B两组接口共享方向/PWM信号，正式套件PID说明要求电机接XH1。当前项目只驱动B/XH1，A/XH2保持关闭。

官方工程的fo_rip_top.cst与另一个AD_test.cst对BN1/BN2的球位定义相反；实际构建采用前者。当前项目依据底板原理图定义，不因“正转”文字与官方计数方向不同而交换引脚或假定驱动失效。方向符号与控制模型仍需结合响应核验。

## 新增有界定PWM测试

原F/B保持10%、150ms。新增J/K为正/反15%，L/M为正/反22%，共用点动空间确认项，并要求新版固件、标定、待机、可信新测量、无故障和停止键释放。固定占空比不保证恒速或固定角度。

每次最多0.5秒，原始编码器相对起点达到±128计数提前结束；从接纳起0.3秒完全没有编码器变化也结束。活动期间再次请求不会延长或反转。SW3/S、标定停止、板级故障、采样看门狗及原有摆臂位置/速度条件保留。R或测量恢复不会自动重启，重新测试必须再次点击。

遥测state=5表示电机测试；199字节v2新增TLV30状态及TLV31有符号相对编码器计数。状态区分时限、位移、手动停止、故障、未检测编码器变化和准入拒收。首次成功测试前位移为0，之后保留起点以观察停止后的滑行；拒收不会建立新起点。它不是每转计数实测结果，也不能代替实际电压、电流或力矩测量。

先自然下垂完成静态与D/U检查。确认小范围运动空间后，在上位机“定PWM电机测试”选15%，正反各一次，等机构回稳后再操作。15%未检测到编码器变化且无故障时，再比较22%的一次响应。保留自动日志及结束原因，当前先用此模式确认驱动和采样质量，不以连续重复起摆代替核验。

235项Python、18组RTL、源码/EXE启动检查通过；Gowin Fmax50.926MHz、Setup/Hold0/0。新版199字节离线90秒4500帧完整交付并记录，无积压溢出或遥测超时。完整证据见[本版验证](project-v0.2.3_validation.json)。实际采样、驱动响应、起摆、长期平衡和抗扰仍须实物验收。
