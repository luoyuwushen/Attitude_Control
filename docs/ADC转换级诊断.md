# ADC 转换级诊断

适用版本：project-v0.2.2 / host-v0.6.2。用于定位 project-v0.2.1 在静止或电机启动后触发的传感器故障，尚不代表自动起摆和平衡已经恢复。

## 已确认的问题与证据缺口

23:19～23:26的五个现场会话共10723帧，CRC与会话内序号连续；R能清除锁存并保留标定，F/B能驱动摆臂。三次G均获准，随后分别因0x2c、0x24、0x24锁存传感器故障，未见首因OTR、轨端或相邻1ms均值跳变位。完整记录见[现场诊断](../Release/host-v0.6.1/validation/field_2319_2326.md)。

当前保护检查约5000个连续三点中值的整窗极差，任一超限都会使1ms窗口无效并锁存。它没有区分短时异常转换与不能形成可信测量的持续异常。现有16个稀疏贡献点的均值也可能漏掉贡献点之间的异常，不能据均值正常就直接取消保护。需要补齐异常数量、连续长度和数字驱动边沿关联，才能确定过滤规则。

官方Interface_test实际是25MHz ADC时钟、每187.5μs取一个瞬时值、约3ms形成16点平均，没有本工程的窗口质量保护；它不是连续转换积分，也不是官方PID_Control.fs的可读源码，不能直接替代现有1ms估速和控制周期。

## 新增记录

ADC采样、三点中值、16点控制均值、质量门限、OTR/轨端保护、控制增益及三项方向参数保持project-v0.2.1行为。新增统计是独立旁路，不用于开放按钮、清除故障或输出驱动。

每个1ms窗口记录：上一完整窗口的控制均值参考、所有中值的最小/最大值、16个贡献值的最小/最大值、最大相邻中值步进、离群数量与最长连续长度、首离群位置、最大步进位置、相应数字驱动状态和边沿距离、近边沿离群数量、中值输出数量及总和。

诊断离群定义为中值与上一完整窗口均值相差超过16码，仅用来统计。参考存在不表示参考窗口健康。统计未饱和且输出数非零时，中值总和除以输出数得到旁路连续均值，未替代控制器的16点均值；稳定的旁路均值本身也不是测量健康证明。

滤后窗口包含三点中值输出。其驱动标签来自被中值选中的原始转换：在ADC下降沿后下一50MHz拍观察数字驱动信号，经过四个ADC周期的流水、总线捕获和中值选择携带。观察相对下降沿有固定20ns偏移，不声称测得模拟采样瞬间电平或干扰消退时间。数字驱动标签为使能、BN2、BN1、PWMB，不包含引脚电压、电流或实际力矩。

最近观测到数字驱动信号变化后不超过100个50MHz时钟（2μs）记为近边沿离群；这是诊断分组，不是屏蔽时间。中值输出间隔为0.2μs，最长连续离群长度仅在本窗口内计数，换算所得是滤后输出序列的时长，不是模拟毛刺宽度。同一原始转换可能被中值重复选中。索引是从0开始的中值输出位置，计数与总和饱和时设置标志；驱动边沿距离也可能饱和，不能把65535一概解释为没有事件。

首次观察到传感器故障时额外锁存最近发布窗口的全部统计、设备毫秒时间及样本累计数；后续正常窗口不覆盖。ADC坏窗处理在下一窗口发布前完成，其统计对应触发坏窗。若D/U标定失败恰逢新窗口发布，所存统计可能比用于判失败的旧输入晚一窗，不能将所有原因的统计都视为精确触发输入。R或新标定实际清除传感器锁存后，这组记录清空。设备毫秒时间是顶层观察到传感器锁存的时刻，不是精确到转换的异常起点。

## 下一次采集

更新两份程序并核对设备版本0x00020002。先自然下垂静止记录约30秒；若出现0x01，保持数秒让首因统计进入日志，再在采样恢复后按一次R，观察是否重现。静态持续异常时到此保留记录，不继续运动。

静态正常后完成D/U，确认周围点动空间并勾选“已确认点动空间，准备按 SW3”，按此前已核验的小范围各做一次F/B点动，每次间隔至少1秒，保留自然回稳段；点动仍为±100‰、最多150ms。暂不反复G起摆或H松手平衡。旧记录还显示正命令对应编码器减小，与当前模型的输入正方向相反；需要与摆杆耦合方向一并统一，不能靠调大驱动处理。
