# ADC 去尖峰与水平盲区

适用：project-v0.3.0 / host-v0.7.0，2026-10-06。目标是消除 ADC 短尖峰引发的误保护，并让手动扶杆经过水平盲区后能直接恢复直立接管。小幅稳定性依据另见 [H 稳定目标与日志基线](H稳定目标与日志基线.md)。

## 故障的直接原因

旧版已有 5 MHz 七点中值和 1 ms 连续平均，但原始轨端码、OTR 绕过滤波直接进入坏窗判据及顶层故障锁存。估计器也把单窗大跳变立即锁为传感器异常。因此，即使中值已经去掉尖峰，原始极值仍能撤销控制并留下 `0x01`。

最新现场日志中的一处故障窗口，原码范围为 0～49，中值输出却在 32～37，离群计数为 0。另一处原码为 0～244，中值在 215～230。它们支持修正“原始轨端等于传感器故障”的规则，不能支持增加全部正常测量的长平均延迟。

用户已确认：顺时针手扶至水平的一小段存在 0→1023 跳变，是当前电位器的盲区。新版将持续轨端标为暂不可测，不再因此锁存 `0x01`。这也意味着该区间不能用两个轨端的平均数伪装成可靠的中间角度。

## 采样与滤波

原始总线捕获、5 MHz ADC 时钟、引脚和七点中值保持原有时序。在中值之后另设控制分支：

1. 正常相邻变化不超过 32 码，直接纳入控制平均，不增加整毫秒延迟。
2. 相对已接受值超过 32 码的变化，要求连续 64 次相互一致的转换才接受；确认期间用前一可信值代替。5 MHz 下确认区间为 12.8 μs。
3. 一窗内至少一半数据被替代，或控制分支跨度仍超过 32 码，该窗不可用；不把长期保持旧数值当作新测量。
4. 中值持续处于 0～1 或 1022～1023 达到确认长度，整个相关窗口标为盲区，包括两端混合窗口。连续 OTR 独立计数，并与中值的中心采样时刻对齐；只有已确认盲区的窗口才豁免硬故障。零星原码端值不会清零 OTR 计数，持续非盲 OTR 仍是采样故障。

64 次是当前工程门限，不是从日志辨识出的模拟毛刺宽度。原有日志记录的是滤后输出序列，无法反推出全部原始 OTR 脉宽。长于确认区间的持续异常不承诺被滤掉，而是交给窗口质量与故障处理。

`adc_mean_q4` 保留七点中值后的原连续均值；新增 `adc_control_q4` 为实际送入标定和估计器的均值。两者单位均为 ADC 码 ×16。保留小数格式不表示提高 ADC 的物理分辨率。原始极值、OTR、方差、离群统计及原始串口帧继续保存。

## 盲区、短异常与持续异常

| 情况 | 测量与输出 | 恢复 |
| --- | --- | --- |
| 原始短尖峰已成功滤除 | 可信控制样本继续使用；记录尖峰提示 | 不要求 R |
| 水平盲区／轨端混合窗 | 测量无效、禁止 D/U/H/G；运行中停止输出并回待机 | 离开后重置差分基线，连续 16 个可信样本恢复就绪；须重新 H |
| 单次跨窗大跳／短坏窗 | 隔离该样本，取消速度历史；运行中停止输出 | 恢复可信测量后允许新 H |
| 持续非盲 OTR／连续 8 个不可用非盲窗口 | 保留硬故障 `0x01` 及首次原因 | 停止、恢复连续健康测量后显式 R |
| 采样断流、跌落、位置或速度越界 | 保留各自保护与故障 | 按对应原因处理 |

经过盲区不会清除先前已发生的硬故障；自动恢复测量也不会自动重启电机。盲区内遥测角度可能保留最后可信值，必须结合测量有效位解释。

新版未实现盲区内的角度预测或 G 跨盲区闭环控制。自动起摆遇到不可测区会结束本次运行；本阶段的验收对象是手扶到有效直立区之后的 H。将 0/1023 简单取模、在盲区持续输出、删除全部 OTR 保护，以及增加固定最小 PWM，都不能解决这里的可观测性问题。

## 协议变化

固件 ID 为 `0x00030000`。默认实时遥测为 v2、219 字节、50 Hz；115200/8N1 下理论线占用约 95.1%。TLV34 位于偏移 213，长度 2，值为 `adc_control_q4:uint16`，仅低 14 位有效；CRC 位于 217～218。旧 TLV16 仍为原均值。

`sensor_flags` 新增 bit5=盲区、bit6=本窗尖峰拒绝提示；bit0 表示控制样本不可用，bit2/3 为估计器有效／成熟，bit1/4 仍是原始窗口／当前 OTR 观测。新版不从原始 OTR 单独推定硬故障。`adc_quality_reason` 保留原诊断位含义，与控制坏窗不再等价。

历史导出保持 schema1 的 32 字节行布局。**精确固件 v0.3.0 的行字段 `adc_mean_q4` 改为控制输入均值**，上位机另加语义标记及 `adc_control_q4` 派生列；v0.2.9 保留原均值语义。实时原始均值仍完整保存。离线分析只对已知固件应用对应解释，不将未来版本猜作本版。

## 稳定性与参考依据

本次去尖峰和误报修复不能解释全部摆臂往返：最新 1 kHz H 记录中，ADC 均值每步最多约一个码，控制公式及积分递推一致，且没有采样故障，但摆幅仍大。H 四项增益与积分保持 S120，避免把多个未经辨识的参数变化混入采样修复。更换反馈参数需要新版本下的实物闭环对照；固定轨迹回放不能证明新闭环稳定。

- [SensorsINI/physical-cartpole 标定说明](https://github.com/SensorsINI/physical-cartpole/blob/master/Docs/calibration.md)明确把电位器盲区放在水平，并用下垂／直立差值确定整圈尺度。参考其区分盲区与有效标定的原则，未移植其 ADC 位数和量程。
- [tommasomarroni/rotary-inverted-pendulum](https://github.com/tommasomarroni/rotary-inverted-pendulum)采用电位器与编码器、滤波后的导数及状态反馈，并记录电机死区和测角分辨率的限制。这些因素需在本机辨识，不能直接复制其参数。
- [ustutt-ipvs-vs/RotatoryInvertedPendulum](https://github.com/ustutt-ipvs-vs/RotatoryInvertedPendulum)提供手扶至直立后接管及越界停止的实现思路；其步进驱动和测量接口与本套件不同。

源码、真实 RTL、指定模型、EDA 构建和实物验收分别记载于 [版本验证](project-v0.3.0_validation.json)。本版尚无上板效果数据，不能把离线通过表述为摆臂已经接近静止。
