# H 小摆幅稳定目标与实测基线

2026-10-06。当前目标从“松手后不倒”提高为“摆臂几乎不摆动”。现有记录证明 H 能保持直立一段时间，但仍有明显往返；ADC 抗尖峰与盲区分类的修改不能代替小摆幅平衡验收。

## 验收目标

在固定物理竖直参照下完成 D/U，H 接管后明确记录实际松手时刻。连续松手至少 **60 秒**，最后 **20 秒**满足以下条件：

| 指标 | 基础目标 | 进阶目标 |
| --- | --- | --- |
| 摆臂峰峰值，即窗口最大角减最小角 | ≤5° | ≤2° |
| 摆杆对标定零度的 RMS | ≤2° | ≤2° |
| 60 秒松手区间内故障、测量失效 | 0 | 0 |
| 松手区间内已记录的满输出样本 | 0 | 0 |

在同一标定和控制参数下，连续 3 次完整试验均满足目标才完成本阶段验收。离线工具只判断单次日志中的目标，单次通过不代表已经完成三次重复验收。

保持时长按首末健康样本的设备时间差计算，不向上补一个遥测周期。摆杆 RMS 采用 `sqrt(mean(theta²))`，保留恒定偏差；去均值标准差小，不代表摆杆接近零度。末段同时报告摆臂首末各 1 秒均值之差及线性漂移率，防止只看保持时间而忽略中心移动。

5°和2°是本阶段的工程验收目标，赛题本身没有给出这两个数字。角度仍依赖 D/U 和名义 1040 计数/圈；合格的数字指标需要与实物观测相符。50 Hz 遥测无法排除帧间瞬态，需结合 1 kHz 连续记录核查。轻推恢复、自动起摆及位置调节仍需分别验收，不能由本项通过推定全部基础要求已完成。

## 逐周期记录的范围

唯一已找到的实物 1 kHz 连续记录为 `host-v0.6.8/captures/control_traces/20260928_140108_638596_2757901f/capture.json`，目录使用 UTC，对应本地21:59会话。588个包CRC通过，4096行采样计数63148～67243连续；记录代表4.096秒采样窗口，首末点跨度为4.095秒。`total_committed=16463` 是本次H总提交数量，不代表缓存保留了全部16.463秒，更不能据此证明60秒达标。

复算的4096行角度映射、位置、反馈命令和方向映射全部一致，4095个速度滤波、积分和计龄间隔全部一致。无故障、输出饱和或积分触界。ADC均值相邻变化为−13～+16 Q4，即−0.8125～+1原码；没有出现超过32码的控制均值突跳。记录中的约11Hz快速分量仍存在，两个速度反馈项共同参与，不能只用50Hz遥测混叠解释，也不能直接等同为机械振动或电气噪声。

滤波的直接目标是减少短脉冲对可信采样和故障判定的影响。小摆幅稳定仍需在新的测量链下取得60秒记录，结合慢往返、积分、输出频谱及执行器响应调整反馈；继续提高速度增益、添加固定最小PWM或取消测量有效性检查，现有证据均不足以支持。既有名义模型未辨识这台机构的摩擦、间隙、驱动动态，模型通过不等于实物接近静止。
