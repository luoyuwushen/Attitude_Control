# ADC 重构与官方 PID 对照

适用：project-v0.2.0 / host-v0.6.0。此版本重构采样质量、连续速度估计、启动准入和实测记录；没有取得官方 PID 源码，也没有把模型仿真作为实物平衡验收。

| [PID 算法如何精确控制电机：从理论到实践](https://blog.csdn.net/m0_73968310/article/details/150869328) | 读到正文；通用电机 PID、离散周期与限幅介绍，不含 J280 源码或实测参数 |
| [PID 算法](https://blog.csdn.net/weixin_44567668/article/details/130075152) | 原站多次失败，本机 HTTP 521；检索到明确标注该原链接的转载，仅辅助确认文章范围，没有以转载参数作为控制依据 |
| [PID 控制算法详解](https://blog.csdn.net/riversuer/article/details/145906551) | 读到正文；通用 PID 教学，示例不是实际机构闭环，不能直接移植其增益；C++ 示例的局部积分项存在未赋值路径 |

PID ZIP 只含三链接文本；本地资料未找到官方 PID 的 RTL、工程或约束文件。下载目录与 Reference 中的 `PID_Control.fs` 均为 18,588,997 字节，SHA256 均为 `f82db8cfdf808904bc0907b3b43e6d6d0b04488c93a2e72f0b6ebdce44278f63`。位流头为 GW2A-55C、Gowin V1.9.12.02，日期 2026-08-31；这些字段不能推出其 ADC 时序、PID 参数或故障处理。

用户确认：同一接线、同一传感器位置下，官方位流能松手平衡，尚未测试下垂自动起摆。这是重要的实物对照，但不等于本工程已通过。官方《上手使用手册》PDF 第 15～16 页的案例流程是扶至直立后 SW1 接管、SW5 退出；不能把官方按键意义套到本工程。PDF 第 9 页的自然下垂显示目标为 990～1040；Interface_test 源码采用 `raw × 4 + 135` 显示尺度。现场本工程下垂原码约 218～220，对应约 1007～1015，不能把 219 与官方显示值直接比较后判为 ADC 错误，也不能把该公式断言为未知 PID 位流的内部公式。

[参考 GitHub 工程](https://github.com/pjj644/gowin-furuta-pendulum)的公开 ADC/引脚方案与本地 J280 并行 ADC 资料不同，未照搬。PID 也不能省略摆臂约束：只稳定摆杆角度可能让主动底座漂移，[密歇根大学控制教程](https://ctms.engin.umich.edu/CTMS/?example=InvertedPendulum&section=ControlPID)明确区分摆杆平衡与底座位置响应。本工程的唯一主动电机驱动摆臂，摆杆为被动自由度，并无第二台摆杆电机。

## 故障证据与根因范围

最新实测会话 `20260927_195439_202885_3c1e778e` 共 4264 帧，CRC 与连续序号均通过，最大接收间隔 79 ms。先进入 BALANCE 约 0.30 s，39249 帧倾角约 −42.47°、故障 0x20、OTR 为零；39251 帧才出现 ADC 1023、OTR 与故障 0x21。故本次首次停机是跌落保护，不能把后续 OTR 当作最初原因。序列对控制有效极性存在反向的疑点，但手扶外力、实际电机输出及测量坐标尚未独立确认，不能单凭这段记录盲翻 `MOTOR_SIGN`。

源码和离线复现证明以下缺陷；它们是真实设计问题，但还不是全部现场现象的唯一根因：

1. **质量与均值不属于同一时间窗。** 旧 OTR 只表示最近一次原始捕获，而控制角度来自 1 ms 的 16 点平均。窗口内 1000/20 混合可形成正常中码 510；短 OTR 也可能在读取均值前消失。旧估算器只审查均值，无法证明整窗可信。
2. **待机人为归零速度。** 旧逻辑把停止命令当作机构静止，导致上位机无法观察手动运动，并使刚启动的速度严重低估，影响直立捕获判断。
3. **ADC 时序验证的边沿错误。** 3PA1030 数据手册 PDF 第 20 页 Figure 22 的数据更新对应下降沿，旧 SDC 和模型用上升沿解释。原 5 MHz 捕获位置仍位于稳定区，边沿错误不能直接证明每次采样错误，但原验证依据须修正。
4. **诊断证据不足。** 只有换算后角度和最近 OTR，无法区分原始输入、混窗、角度换算与控制后果；后续故障还会掩盖第一原因。

## 本版实现

| 层次 | 行为 |
| --- | --- |
| 并行捕获 | 维持 5 MHz、上升后 80 ns，即前一下降后 180 ns；10 位总线和 OTR 同拍寄存，不分别同步每一位 |
| 窗口质量 | 仍以 16 点和保留 Q4 平均；对窗口全部 5 MHz 捕获统计 min/max/OTR。OTR、轨端码或窗口跨度超过 32 码均标为坏窗；坏窗保留原始证据，不能因均值落在中间而放行 |
| 估算器 | 已标定后在待机、运行和故障状态持续估计速度；仅标定、坏样本和断流恢复重建微分历史。16 个连续可信样本后才具备启动成熟度，不能把计数条件当作滤波完全收敛 |
| 标定 | D/U 只采新鲜、质量合格的窗口；标定显示完成与测量就绪为独立条件。平均值的小数保存在 Q4 寄存器，界面端点显示整数原码 |
| 控制入口 | G/板上 SW2 保持自动起摆；H 为独立直立接管，仅在 IDLE、标定正常、测量成熟、无故障、`abs(theta_q10)<268` 且 `abs(omega_q10)<3584` 时直接 BALANCE。H 拒收不退回起摆，同拍 H/G 以 H 为准 |
| 保护 | 保留 SW3、采样 2 ms 超时、位移/速度/跌落保护。首故障独立锁存，后续 OTR 不覆盖；S 不清首故障。顶层在停机时接受新鲜、质量合格的 D/U 请求，或收到 R 时清除；这不是标定成功确认，持续异常会重新锁存 |
| 上位机 | 主控制区显示 ADC 原码、均值、窗口范围、质量、D/U、固件身份、请求及门控后命令、首故障；自动日志保存设备发送的 TLV |

门控后命令是送往 PWM 模块的软件输入，仍非实测电压、电流或力矩，也不是周期边界已经生效的占空比。Q4 平均没有增加 ADC 的物理分辨率；最新原码与最近完成估计具有不同时间尺度。坏窗时姿态可能保留上次可信值，应结合质量位及采样计数，不可把重复角度当成新采样。

SDC 使用下降沿参考、setup 9/end、hold 9/end，对应有效捕获前 180 ns 的发射和捕获后 20 ns 的下一发射。最大输入延迟 45 ns 是设计预算；数据手册的 25 ns 是典型值而非保证最大值，EDA 通过只证明该预算下满足时序，不替代实板捕获裕量测量。

## 为什么暂不直接改为博客 PID

把同一连续 ADC 区间的角域 PD 改写成原码域 PD，只是换单位，不能修复混窗、OTR 或控制方向。未知官方增益也无法从 `.fs` 得到。此版保留已有能量起摆与名义四状态反馈作为可追溯基线；新增 H 将直立平衡与起摆激励分开，使官方已证实的“手扶接管后松手平衡”有独立对照入口。不能声称本版已复刻官方 PID 或已解决全部实板失稳。

如果新证据显示采样可信、极性一致而反馈仍不合适，下一层控制方案是固定 1 ms 的摆杆 PD 加有限幅、渐入的摆臂慢外环；对测量做滤波微分，先不加摆杆积分。增益、外环方向及摩擦补偿由受限实测确定，禁止从教学例程抄数值或靠提高 PWM、扩大跌落门限掩盖不稳定。

## 验收次序

1. 停机采集下垂、水平、直立及缓慢往返，比较原码、均值、窗口范围、OTR、端点和换算角；此项不需电机运动。相同安装条件优先保留，避免同时改机械相位和软件。
2. 结合已有受限 F/B 点动及停止响应，独立核验电机、编码器、摆杆坐标关系；未知方向时不执行 H/G。确认框是操作者声明，不是 FPGA 对物理方向的自动认证。
3. 用 H 对照官方的直立接管能力，记录松手与外力时刻；确认电机有效方向与增益后验收持续平衡和轻推恢复。
4. 最后验收 G/SW2 从自然下垂自动起摆、重复捕获及长时日志。赛题基础要求见选题指南 PDF 第 14 页，H 成功不能替代下垂自动起摆。

离线回归、RTL、Gowin、EXE 与实物证据分别记录在 `project-v0.2.0_validation.json` 和 `验证记录.md`。原始现场日志、官方位流和旧发布包保留用于对照；Reference 原件不改动。
